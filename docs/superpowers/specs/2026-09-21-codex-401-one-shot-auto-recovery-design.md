# [已废弃] Codex HTTP 401 永久一次自动更新设计

**原始日期：** 2026-09-21
**废弃日期：** 2026-10-22
**替代文档：** `docs/superpowers/specs/2026-10-22-daily-auto-recovery-cooldown-design.md`

> 本文档记录的“同一凭证永久只自动更新一次”规则已被废弃，不得在后续 CPAM 更新或合并中恢复。

## 当前生效规则

- 仅在已启用 Codex 凭证存在新的已确认 HTTP 401 / 重登录信号且策略开关开启时自动恢复。
- 同一物理凭证滚动 24 小时最多自动尝试一次；计时从 worker 实际 claim 自动任务时开始。
- 自动成功和自动失败均进入 24 小时冷却。冷却到期不会自行重试；必须收到下一条新的合格 401 信号。
- 人工恢复随时可用，不重置或占用自动冷却。
- `auto_attempted_at_ms` 保留为最近一次自动 claim 的脱敏审计时间戳，不包含 Token 或认证 JSON。

详细实现和验收以 2026-10-22 的替代设计为准。
